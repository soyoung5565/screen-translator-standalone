屏幕翻译器 · 控制面板 UI 重设计稿

PyQt5 桌面工具的面板重设计。客户区固定 400 × 268，系统标题栏由 Windows 绘制、不在本稿范围内。 面板从「三行等权重表单」改成「顶部状态读数 + 三项设置 + 唯一主操作」： 状态提到最上方成为仪表盘读数，贴字模式改为二选一分段控件，退出操作降到面板最底部的极低权重文字。 全部交互行为不变，只改视觉层级与信息优先级。

客户区 400 × 268 px 标题栏 系统原生，另计 主题 GitHub Dark 系（暗色） 网格 4 / 8 px 状态 4 种并排 实现 Qt Style Sheets 可表达

05

设计说明

改动点、为什么改、与现有代码的对应关系、Qt 落地时的能力边界。

A改动点与理由

  • 状态行提到顶部 —— 状态栏原本是底部 10px 灰字，翻译中（95% 的时间）几乎看不见。现在 LED + 状态词占据顶部 40px，是整个面板第一眼落点。
  • 层级靠对比度建立 —— 不再靠颜色数量。主按钮 13px/600 实心，次要项 12px 标签 + 描边控件，辅助操作 10px 文字，危险操作 10px 淡灰。四档一眼可分。
  • 退出降权 —— 原来是红色描边的 34×34 按钮，和主按钮并排，视觉上比「开始翻译」还重。现在是面板最底部的 10px 淡灰文字「退出」，红色只在真正报错时出现。
  • 贴字模式改分段控件 —— 两个选项一眼看全、一次点击切换，不用展开下拉才知道有第二种。附 10px 说明解释差异。
  • 下拉框描边提到 3:1 —— 原来纯色块看不出能点。现在 1px --border-ctl（#6e7681，对底色 3.77:1）+ 明确的下拉箭头。
  • 滑块补上数值语义 —— 数值区第二行写「最快 3 秒一次」，直接回答「这是帧率还是请求间隔」。
  • 去掉重复标题 —— 系统标题栏已经写着「屏幕翻译器」，面板内不再重复标题，把这 40px 让给状态读数。

CQt 落地能力边界

QSS 可表达 圆角、1px 描边、背景色、字体字号字重、padding、:hover / :pressed / :disabled / :focus、分段控件 :checked、上下边框、文本对齐。

需自定义绘制 状态灯：QSS 画不了圆点，用一个 LedDot(QWidget) 的 paintEvent 画圆；「翻译中」的呼吸效果用 QPropertyAnimation 改 opacity，1.6s 往返。降级：不做呼吸动画，改成实心绿点 + --accent 外发光边框（QSS border 实现），视觉上仍然是「活着」的。

需自定义绘制 图标：下拉箭头、清缓存箭头沿用现有 combo_arrow_path() 方案 —— 运行时用 QPainter 画 PNG 存临时目录，QSS 里 url(...) 引用。新增图标用同一个函数扩展。

QSS 不支持 box-shadow：按钮不投影，改用「描边 + 底色分层」制造层级（主按钮 1px 深边、按压时底色变深 + 下移 1px 模拟按压）。text-overflow：QSS 没有 ellipsis，状态词过长时用 QFontMetrics.elidedText() 在代码里截断。伪元素：QSS 没有 ::before，所有装饰都必须是真实控件或自绘。

需确认 letter-spacing：QSS 从 Qt 5.11 起支持，若目标环境 PyQt5 版本偏老则该属性被忽略 —— 徽标仍可读，只是字距略紧。

D配色理由

整份稿子只用一个品牌绿（--accent 族），其余全是中性灰。绿只在三处出现：运行中 LED、滑块填充、主按钮底色 —— 每一个都承担明确的语义。

对比度实测（WCAG）：主文字 14.6:1、次文字 5.6:1、禁用态 3.8:1、主按钮白字 5.1:1、停止按钮白字 4.7:1、错误文字 6.9:1、控件描边对底色 3.8:1。

两处与现状不同、且是有意为之：
· 主按钮底色从 #2ea043 改为 #1a7f37 —— 原配色白字只有 3.37:1，达不到 4.5:1；新配色 5.08:1。
· 停止按钮 hover 从「变亮」改为「变暗」（#9e6a03 → #7d5303）—— 变亮后白字只剩 3.38:1，变暗后 6.75:1。

E未采纳的建议与理由

  • 「目标语言」改写标签 —— 建议稿写「目标语言」，但既有代码与文案是「翻译方向」，且它同时管源语言与目标语言（自动→中文 / 中文→英文…）。保持原文案，避免改坏 LANG_PAIRS 的语义。
  • 退出放进标题栏 —— 本项目用系统标题栏，无法在标题栏右侧塞按钮。退到底栏最右下角的 10px 灰字。
  • 退出继续用 ✕ 图标 —— 系统标题栏右上角已经有一个 ✕（当前行为是收起到托盘）。面板里再放一个 ✕ 会被误认成同一个按钮，且两处行为不同。改用文字「退出」，彻底消除歧义。
  • 保留 ✕ 的红色 —— 红色是错误色。退出是常用操作而非事故，用红色会持续制造紧张感。红色只留给 401 这类真实错误。

F验收对照

  • 改写 _setup_ui —— 新增 LedDot 子类与状态带容器；mode_combo 换 QButtonGroup；三个辅助按钮改为文字/图标形式。窗口仍 setFixedSize(400, 268)。
  • ui_preview.py —— 仍用原生 windows 插件渲染；grab() 可截到自绘 LED 的静态帧，呼吸动画在预览图里呈现为某一帧的透明度，可接受。
  • 测试全绿 —— 本稿不改任何坐标逻辑与热键注册；Ctrl+Alt+S / H / Q 三组热键与托盘行为完全未动。
  • --selftest —— 与本稿无关（验的是打包资源、配置路径、解析器、视觉链路、墨迹校正）。
  • 快捷方式 —— 与本稿无关。
